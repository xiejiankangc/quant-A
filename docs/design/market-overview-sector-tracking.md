# 市场整体概览与板块变化追踪（设计草案）

> 分支：`feature/market-overview-sector-tracking`
> 状态：草案 v0.3（板块体系定为东财行业+概念，无地域；其余同 v0.2）

## 1. 目标与非目标

目标：

- 对市场整体做多日连续跟踪，先看清「大盘 → 板块 → 个股」三层的状态与变化；
- 支持板块间、板块内个股间的关系对比；
- 给定几只股票与权重后，计算持仓组合的 β。

首版非目标：

- 不做自动化交易，不做盘中实时盯盘（以日线节奏为主）；
- 不输出荐股、买卖点、目标价或收益承诺；
- 不把「热度/强度」直接等同于投资结论。

## 2. 分层跟踪模型

| 层级 | 关注点 | 关键指标 | 数据来源 |
| --- | --- | --- | --- |
| 市场层 | 量能持续跟踪 | 指数点位、日成交额、量能趋势、涨跌家数 | `index history/snapshot`、`market snapshot`（分页）、`market panel`（本地库） |
| 板块层 | 板块间关系 | 板块涨跌幅、成交额、量能变化趋势、区间强度、上涨后回撤、相对大盘超额 | 东财行业/概念板块（列表、历史、成分，走 `market_data`） |
| 板块内个股层 | 个股间关系 | 市值分组、涨跌幅、成交量/成交额、量能变化趋势 | 东财板块成分接口 + `market snapshot/history` + 东财个股信息 |
| 个股层 | 单票状态 | 换手率、形态、筹码结构 | `market history` 派生形态 + 东财补换手率；筹码 P2 |

三层关系可以落到同一份宽表：每个交易日，板块指标由成分股聚合，个股指标挂在所属板块下，市场指标作为基准列。多日跟踪以该宽表为基础做切片。

## 3. 数据源与已验证字段

金融取数优先走 hithink-finance 系列技能/CLI，板块层单独走东财。以下字段已在本机实测（CLI 0.1.5 + 东财 `em.fetch` 自适应通道）：

| 能力 | 已验证字段 | 备注 |
| --- | --- | --- |
| `symbol search/list` | `thscode/ticker/name/exchange/asset_type` | 名称到 thscode 消歧入口 |
| `market snapshot` | `last_price/price_change/price_change_ratio_pct/open/high/low/prev_price/volume/turnover` | `turnover` 是成交额，不是换手率 |
| `market history` | `date_ms/open/high/low/close/volume/turnover`，`--adjust forward/backward/none` | 单标的、单次窗口最长 10 年 |
| 东财行业板块列表（实测） | 板块代码/名称/价格/涨跌幅/成交额，当前 496 个 | clist `fs=m:90+t:2+f:!50` |
| 东财概念板块列表（实测） | 同上，当前 504 个 | clist `fs=m:90+t:3+f:!50` |

| `financials balance-sheet` | 资产、负债、股东权益等 | 不含股本字段 |

机器级注意事项：

- 本机 `market history` 默认 `--source auto` 会先查本地 DuckDB；当前本地库未初始化（`data status` 为 version 0）时会报错。实现脚本在本地库同步完成前显式传 `--source remote`。
- 本地 `market panel`（`v_daily` 含 OHLC/volume/amount）依赖每台机器先做一次 `hithink-finance data init` + `data sync`；这是机器级步骤，不入库。
- akshare 的默认行情请求在本机会被系统代理拦住；东财板块列表、历史、成分与个股信息必须复用 `market_data/em.py` 的「系统代理 → 直连 → curl」通道（含 `push2his`），不另写裸请求。
- 所有远端调用使用系统凭据；API Key 不得写入代码、日志、文档或 Git。

## 4. 指标口径草案

所有强度类指标先做「定义 → 样例数据验证 → 固定口径」三步，避免直接拍数值阈值。

### 4.1 市场量能与量能变化趋势

- 基准：上证指数（`000001.SH`）日成交额，可选叠加沪深 300 或全市场成交额；
- 量能变化趋势：5/20 日均量比、较昨日环比、较 5 个交易日前同比、当日量能分位（近 60/120 日）、当日量/近 20 日均量；
- 宽度（可选）：`market snapshot` 分页统计上涨/下跌/平盘家数；涨停/跌停家数走 `special-data`。

### 4.2 板块强度与「上涨后回撤」

板块体系固定为东财行业（496）+ 概念（504），不做地域板块。候选口径：

- 区间强度：板块 N 日（如 5/10/20）涨跌幅在全板块中的分位；
- 相对强度：板块 N 日涨跌幅 − 上证指数 N 日涨跌幅；
- 回撤强度：区间最高点 → 区间末的最大回撤，与区间涨幅结合成「涨幅/回撤比」；
- 量能变化趋势：板块当日量/近 20 日均量、5/20 日均量比，与市场量能方向对齐；
- 板块换手率：东财板块历史自带换手率字段（f61），可作为板块热度的辅助列；
- 量能配合：回撤期间量能收缩还是放大，标记「缩量回撤 / 放量回撤」。

这组指标回答「哪些板块涨过、当前回撤到什么程度、量能是否健康」，但不据此自动给买卖结论。

### 4.3 板块内个股关系

- 市值分组：大/中/小盘（阈值待定，先看全市场市值分布再固定）；板块成分接口已一次性给每个成分的总/流通市值和换手率，优先批量取，个股快照只补涨跌幅与量；
- 涨跌与量：个股涨跌幅、成交额占板块成交额比、当日量/近 20 日均量（量能变化趋势）；
- 输出：板块内「涨跌幅 × 市值」散点/分组汇总，识别领涨是小盘还是大盘。

### 4.4 个股维度

- 换手率：东财补源后展示当日值与近 5/20 日均值，构成换手率趋势；
- 形态（v1 用日线派生）：均线排列、N 日新高/新低、区间振幅、最大回撤、放量/缩量比；
- 筹码结构：P2，首版只做数据可得性验证，不先承诺结论化指标。

## 5. 持仓组合：β 与集中度

报告固定用最近 60 个交易日作为统计窗口；基准缺省为上证指数（`000001.SH`），允许切换沪深 300。

### 5.1 β 是什么

β 衡量「组合相对基准的敏感度」：基准涨 1% 时，组合平均大致涨 β%。β=1 表示基本跟着基准走；β>1 表示放大基准波动（涨得多也跌得多）；0<β<1 表示比基准稳；负 β 表示与基准反向。它不是好坏分数，只是弹性大小。

计算过程：

- 输入：股票 thscode 列表 + 权重（缺省等权）；
- 数据：`market history --adjust forward` 取个股后复权日收盘，`index history` 取基准收盘；
- 对齐：按共同交易日对齐，计算日收益率 `r_t = close_t / close_{t-1} - 1`；
- 个股 β：`β_i = Cov(r_i, r_m) / Var(r_m)`，或对基准收益率做一元回归；
- 组合 β：`β_p = Σ w_i * β_i`；
- 输出：个股 β、回归 R²、组合 β。

### 5.2 集中度 /「同涨同跌」

「过去同涨同跌、没有分摊」在报告里用四个指标量化，都基于同一 60 日收益序列：

- 平均两两相关系数：对组合内每两只股票的 60 日收益算相关系数再取平均。接近 1 表示同涨同跌明显、分散效果差；接近 0 或为负表示分摊较好。
- 权重集中度：`HHI = Σ w_i²`，并给出「有效持仓数 = 1 / HHI」。等权持 5 只时 HHI=0.2、有效数=5；重仓单票时有效数接近 1。
- 分散化比率：`组合波动率 / 按权重加权的个股平均波动率`。该值越接近 1，说明组合波动几乎就是各股波动的加权平均，没吃到分散红利；明显小于 1 才说明有分摊。
- 与基准相关性：组合 60 日收益与基准收益的相关系数，配合 β 一起看大盘驱动的占比。

输出形式：相关系数矩阵（热力图）、相关最高/最低的股票对、上述四个汇总值。相关系数只描述同向性，不解释因果，报告里不把高相关自动写成「风险坏」。

注意事项：

- 停牌/缺失日按共同交易日对齐，不凭空插值；
- 个股与基准统一复权口径（组合 β 用后复权收益序列即可，成交额类指标用不复权）；
- 报告必须标注窗口（60 交易日）与基准，不隐藏假设。

## 6. 里程碑建议

| 阶段 | 交付物 | 验收 |
| --- | --- | --- |
| M0 | 报告骨架 + 标的输入格式 + 数据抓取层 + 本地缓存约定 | 一条命令能从 CLI/东财抓到指定窗口数据并落盘，报告模板可渲染 |
| M1 | 市场量能与量能变化趋势报告 | 输出指数日成交额、量能趋势与分位，数据与原始接口值可对账 |
| M2 | 东财行业+概念板块 + 强度/回撤/量能趋势 | 输出东财行业、概念板块的强度表与回撤、量能标注 |
| M3 | 板块内个股关系 | 从成分接口批量取市值/换手率，输出板块内市值分组、涨跌、量能趋势汇总 |
| M4 | 个股维度 | 换手率趋势 + 形态指标可输出；筹码结构完成可行性验证 |
| M5 | 组合 β 与集中度报告 | 给定代码与权重，输出个股 β、组合 β、相关系数矩阵与集中度指标 |

## 7. 决策状态

已确认：

1. 板块体系：直接使用东财行业板块（496）与概念板块（504），不用地域板块；同花顺板块目录不再使用，同花顺仅保留个股行情、市场基准指数与估值等能力；
2. 东财补源：允许在 `market_data/` 增加个股信息访问层，补市值、股本、换手率；
3. 量能变化趋势：纳入市场、板块、个股三层指标；
4. β：窗口固定 60 个交易日，基准默认上证指数（可切换沪深 300）；
5. 交付形态：先以报告形式输出，附带可复用的中间数据集文件。

仍待确认：

- 报告渲染格式：Markdown 转 HTML，还是直接生成 HTML/PDF；
- 市值分组（大/中/小盘）的具体阈值；
- 筹码结构是否纳入首版（当前建议保持 P2 后置）。
