# 市场整体概览与板块变化追踪（设计草案）

> 分支：`feature/market-overview-sector-tracking`
> 状态：草案 v0.1，待确认后进入实现

## 1. 目标与非目标

目标：

- 对市场整体做多日连续跟踪，先看清「大盘 → 板块 → 个股」三层的状态与变化；
- 支持板块间、板块内个股间的关系对比；
- 给定几只股票与权重后，计算持仓组合的 β。

首版非目标：

- 不做自动化交易，不做盘中实时盯盘（以日线节奏为主）；
- 不输出荐股、买卖点、目标价或收益承诺；
- 不把「热度/强度」直接等同于投资结论。

## 2. 分层跟踪模型

| 层级 | 关注点 | 关键指标 | 数据来源 |
| --- | --- | --- | --- |
| 市场层 | 量能持续跟踪 | 指数点位、日成交额、量能趋势、涨跌家数 | `index history/snapshot`、`market snapshot`（分页）、`market panel`（本地库） |
| 板块层 | 板块间关系 | 板块涨跌幅、成交额、量能变化、区间强度、上涨后回撤、相对大盘超额 | `index catalog/history/snapshot`、`index constituents` |
| 板块内个股层 | 个股间关系 | 市值分组、涨跌幅、成交量/成交额 | `market snapshot`、`market history`，市值需补源 |
| 个股层 | 单票状态 | 换手率、形态、筹码结构 | `market history` 派生形态；换手率与筹码需补源 |

三层关系可以落到同一份宽表：每个交易日，板块指标由成分股聚合，个股指标挂在所属板块下，市场指标作为基准列。多日跟踪以该宽表为基础做切片。

## 3. 数据源与已验证字段

金融取数优先走 hithink-finance 系列技能/CLI。以下字段已在本机实测（CLI 0.1.5）：

| 能力 | 已验证字段 | 备注 |
| --- | --- | --- |
| `symbol search/list` | `thscode/ticker/name/exchange/asset_type` | 名称到 thscode 消歧入口 |
| `market snapshot` | `last_price/price_change/price_change_ratio_pct/open/high/low/prev_price/volume/turnover` | `turnover` 是成交额，不是换手率 |
| `market history` | `date_ms/open/high/low/close/volume/turnover`，`--adjust forward/backward/none` | 单标的、单次窗口最长 10 年 |
| `index catalog` | `thscode/name`，`--tag industry` 实测 320 个行业指数 | 还有 `cn_concept/region/tszs` |
| `index constituents` | `thscode/ticker/name` | 只给成分关系，不含权重与市值 |
| `index history/snapshot` | 与个股行情同构的 OHLC + volume/turnover | 板块量与价格序列来源 |
| `valuation snapshot` | `pe_ttm/pe_mrq/pb_mrq/ps_ttm/pcf_ttm` | 当前估值，不含市值 |
| `financials balance-sheet` | 资产、负债、股东权益等 | 不含股本字段 |

机器级注意事项：

- 本机 `market history` 默认 `--source auto` 会先查本地 DuckDB；当前本地库未初始化（`data status` 为 version 0）时会报错。实现脚本在本地库同步完成前显式传 `--source remote`。
- 本地 `market panel`（`v_daily` 含 OHLC/volume/amount）依赖每台机器先做一次 `hithink-finance data init` + `data sync`；这是机器级步骤，不入库。
- 所有远端调用使用系统凭据；API Key 不得写入代码、日志、文档或 Git。

### 3.1 数据缺口

| 指标 | hithink CLI 现状 | 候选补法 | 建议优先级 |
| --- | --- | --- | --- |
| 市值（总市值/流通市值） | 快照、估值、成分接口均无 | 东财个股信息（akshare，收进 `market_data` 扩展层）；或总股本 × 价格近似 | P0，板块内市值分组依赖它 |
| 换手率 | `snapshot.turnover` 是成交额 | 东财个股信息直接给换手率；或 `volume / 流通股本` | P1 |
| 股本（总股本/流通股本） | 财务接口未提供 | 东财个股信息/交易所数据 | P1，同时服务市值与换手率 |
| 筹码结构 | 无对应能力 | 东财筹码分布（90% 成本区间、获利比例、平均成本）或自定义成本分布近似 | P2，首版可后置 |

按 AGENTS.md 约定，新增的行情直连接口统一收敛在 `market_data/` 下，hithink CLI 仍作为第一路由；`scripts/verify_market_data.py` 之外的脚本不直接散落行情访问。

## 4. 指标口径草案

所有强度类指标先做「定义 → 样例数据验证 → 固定口径」三步，避免直接拍数值阈值。

### 4.1 市场量能

- 基准：上证指数（`000001.SH`）日成交额，可选叠加沪深 300 或全市场成交额；
- 量能趋势：N 日均量 / M 日均量（如 5/20）、当日量能分位（近 60/120 日）；
- 宽度（可选）：`market snapshot` 分页统计上涨/下跌/平盘家数；涨停/跌停家数走 `special-data`。

### 4.2 板块强度与「上涨后回撤」

候选口径：

- 区间强度：板块 N 日（如 5/10/20）涨跌幅在全板块中的分位；
- 相对强度：板块 N 日涨跌幅 − 上证指数 N 日涨跌幅；
- 回撤强度：区间最高点 → 区间末的最大回撤，与区间涨幅结合成「涨幅/回撤比」；
- 量能配合：回撤期间量能收缩还是放大，标记「缩量回撤 / 放量回撤」。

这组指标回答「哪些板块涨过、当前回撤到什么程度、量能是否健康」，但不据此自动给买卖结论。

### 4.3 板块内个股关系

- 市值分组：大/中/小盘（阈值待定，先看全市场市值分布再固定）；
- 涨跌与量：个股涨跌幅、成交额占板块成交额比、量能相对自身 N 日均量；
- 输出：板块内「涨跌幅 × 市值」散点/分组汇总，识别领涨是小盘还是大盘。

### 4.4 个股维度

- 换手率：P1 补源后展示当日与 N 日均值；
- 形态（v1 用日线派生）：均线排列、N 日新高/新低、区间振幅、最大回撤、放量/缩量比；
- 筹码结构：P2，首版只做数据可得性验证，不先承诺结论化指标。

## 5. 持仓组合 β

可行，且所需数据已经验证齐备：

- 输入：股票 thscode 列表 + 权重（缺省等权）、基准（缺省上证指数 `000001.SH`）、窗口（缺省 60 或 120 个交易日）；
- 数据：`market history --adjust forward` 取个股后复权日收盘，`index history` 取基准收盘；
- 对齐：按共同交易日对齐，计算日收益率 `r_t = close_t / close_{t-1} - 1`；
- 个股 β：`β_i = Cov(r_i, r_m) / Var(r_m)`，或对基准收益率做一元回归；
- 组合 β：`β_p = Σ w_i * β_i`；
- 输出：个股 β、回归 R²、组合 β，可选滚动窗口 β 曲线。

注意事项：

- 停牌/缺失日按共同交易日对齐，不凭空插值；
- 个股与基准统一复权口径（组合 β 用后复权收益序列即可，成交额类指标用不复权）；
- β 对窗口长度和基准选择敏感，报告里必须标注窗口与基准，不隐藏假设。

## 6. 里程碑建议

| 阶段 | 交付物 | 验收 |
| --- | --- | --- |
| M0 | 分支内骨架：标的输入格式、数据抓取层、本地缓存约定 | 一条命令能从 CLI 抓到指定窗口数据并落盘 |
| M1 | 市场量能跟踪报告 | 输出指数日成交额、量能趋势与分位，数据与 CLI 原始值可对账 |
| M2 | 板块目录 + 板块行情 + 强度/回撤 | 输出全行业板块强度表与回撤标注 |
| M3 | 板块内个股关系 | 输出板块内市值分组、涨跌、量能汇总 |
| M4 | 个股维度 | 换手率 + 形态指标可输出；筹码结构完成可行性验证 |
| M5 | 组合 β | 给定代码与权重，输出个股 β 与组合 β，附窗口与基准 |

## 7. 待确认的决策点

1. 板块体系：同花顺行业（`index catalog --tag industry`）还是东财行业分类；
2. 市值/换手率缺口：是否允许在 `market_data/` 增加东财个股信息访问层；
3. β 默认值：基准（上证指数/沪深 300）与窗口（60/120 交易日）；
4. 最终交付形态：本地 Markdown/HTML 报告、parquet/csv 数据集，还是 CLI 子命令。

## 8. 边界声明

- 本模块只提供数据、中立统计与可复现口径，不构成投资建议；
- 真实数据不可用时如实报告原因，不用模拟或近似数据冒充；
- 机器级本地库、缓存与凭据不入库；代码、文档、锁文件等入库内容遵守仓库约定。
